# Delta Force 自动钓鱼声音检测器

这是一个适用于 Windows 的自动钓鱼脚本。程序会监听游戏的鱼咬钩音效，并根据检测结果自动执行抛竿和收竿操作。

> 请只在游戏规则允许自动化的情况下使用。使用者需要自行承担账号限制或处罚风险。

## 重要限制

- 目前仅限使用 **入门台钓竿**，才能完成整套全自动流程。
- 必须使用 **管理员身份**运行程序，否则游戏可能无法接收到脚本发送的按键。
- 游戏必须保持在最前面，建议使用无边框窗口模式。
- 程序需要游戏声音，不能把钓鱼音效完全静音。
- 建议关闭其他声音，只保留游戏的“音效”音量，以提高咬钩检测的准确度。
- 由于程序根据游戏音效自动执行操作，请远离可能产生干扰声音的来源，包括但不限于：干员、人机、车站和载具。

## 游戏按键设置

进入 Delta Force 的按键设置，找到原本使用鼠标左键的 **射击/钓鱼操作**。请保留鼠标左键，并额外添加 `F6` 作为第二按键：

```text
主要按键：鼠标左键（保持不变）
第二按键：F6
```

设置完成后，请先在游戏中手动按一次 `F6`，确认它可以正常抛竿或收竿。

## 程序运行流程

1. 程序按一次 `F6`。
2. 等待 `1.5 秒`后再次按 `F6`，用于兼容每抛五次竿出现的挂鱼饵操作。
3. 从第二次按 `F6` 开始计时，前 5 秒不监听声音。
4. 从第 5 秒开始监听鱼咬钩音效。
5. 检测到咬钩后，随机等待 `0.214–0.578 秒`，然后按 `F6` 收竿。
6. 如果满 20 秒仍未检测到咬钩，也会按 `F6` 收竿。
7. 收竿后随机等待 `7–9 秒`，让动画播放完成。
8. 再次按 `F6` 并重复以上流程。

随时按 `F8` 可以停止程序。

## 需要的文件

请确保下面这些文件位于同一个文件夹：

```text
fishing_bot.py
start_fishing_bot.bat
bite_clean_10.5_to_12.wav
```

声音模板文件 `bite_clean_10.5_to_12.wav` 不能改名或删除，否则程序无法检测鱼咬钩。

## 如何启动

### 用户需要安装什么

运行本程序需要：

- Windows 10 或 Windows 11。
- 64 位 Python 3。
- 首次启动时需要连接网络，以便下载程序依赖。
- Delta Force 游戏本体。

安装 Python 时，请勾选安装程序底部的 **Add Python to PATH**（把 Python 添加到系统路径）。建议同时保留 Python Launcher（`py`）。

用户不需要安装 Git、GitHub Desktop 或 Razer 软件。下载 GitHub 仓库的 ZIP 文件并完整解压即可。

`start_fishing_bot.bat` 会自动检查并安装以下 Python 组件：

```text
soundcard
numpy
scipy
keyboard
```

如果自动安装失败，可以打开 PowerShell，手动运行：

```powershell
py -m pip install soundcard numpy scipy keyboard
```

如果系统提示找不到 `py`，请重新安装 Python，并确认已经勾选 **Add Python to PATH**。

### 启动步骤

1. 找到 `start_fishing_bot.bat`。
2. 右键点击该文件。
3. 选择 **以管理员身份运行**。
4. Windows 弹出权限提示时选择“是”。
5. 程序显示声音设备列表后，通常直接按 `Enter` 使用推荐设备即可。
6. 再按一次 `Enter`，然后在 5 秒倒计时内切换回游戏。

## B站或其他程序的声音仍然造成干扰

脚本会列出 Windows 播放设备，并通过所选设备的唯一端点 ID 打开 loopback。请选择游戏实际使用的设备 A，不要只根据“默认设备”盲选。

如果已经把 B站视频输出到设备 B，但它仍然影响设备 A 的检测，请运行 `test_output_isolation.bat`：

1. 选择设备 A 的编号。
2. 让游戏保持安静，只播放已经输出到设备 B 的 B站视频。
3. 开始测试并等待 8 秒。
4. 播放生成的 `output_isolation_test.wav`。

如果测试文件中听不到 B站声音，说明 A/B 端点已经正确隔离，可以在机器人中选择同一个设备 A。如果测试文件中能听到 B站声音，说明声音在进入脚本前已经被 Windows、声卡驱动或虚拟混音软件合并；这不是声音匹配算法造成的。

遇到后一种情况时，请检查 Windows 音量混合器中的浏览器输出设备，修改后完全重启浏览器，并关闭“立体声混音”“侦听此设备”以及声卡软件中的监听、镜像或虚拟混音功能。

## 无法操作时怎么办

如果程序能检测到咬钩声音，但游戏没有执行 `F6`，请依次检查：

1. 在游戏中物理按下 `F6`，确认它可以控制抛竿和收竿。
2. 确认没有删除原来的鼠标左键绑定，而是把 `F6` 添加为第二按键。
3. 确认 `start_fishing_bot.bat` 是以管理员身份运行的。
4. 保持游戏窗口在最前面，建议使用无边框窗口模式。
5. 如果游戏以管理员身份启动，脚本也必须以管理员身份启动。

如果手动按 `F6` 都无法操作钓鱼，请先重新设置游戏按键；这种情况不是声音检测问题。

## 文件说明

- `fishing_bot.py`：自动钓鱼主程序。
- `start_fishing_bot.bat`：自动安装依赖并启动程序。
- `bite_clean_10.5_to_12.wav`：鱼咬钩声音模板。
- `test_output_isolation.py` / `test_output_isolation.bat`：检查两个 Windows 输出设备是否真正隔离。
